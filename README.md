# GvG Info

A personal Guild Wars 1 GvG portal: skill database, saved skill templates with copyable codes, and a mechanics
knowledge base. Match history, meta and a build explorer (from gvg.report) are being added next.

Open the site: https://itsha12.github.io/gvginfo/

## Pages
- **My templates** — folders of bars and their variations, with skill-bar images, tooltips at your ranks and copy buttons.
- **Skills** — every PvP-legal skill, filterable by profession, attribute, type, conditions caused or removed, cost.
  Add your own tested notes to any skill.
- **Knowledge** — mechanics, GvG rules and your verified findings.
- **Settings** — paste a GitHub key once per browser so the site can save changes.

## Data sources
Skill data: Guild Wars Wiki (pulled 2026-10-08). Template id mapping for PvP skills: Guild Wars Wiki and gvg.report.
Unofficial fan project; Guild Wars content belongs to ArenaNet.
